Substack to PDF

Paste a Substack post URL and get a shareable PDF, Markdown, or HTML file with text and images, for when an LLM can't fetch the page.

Works with *.substack.com, custom-domain Substacks, and substack.com/@user/p-123 links. Paywalled posts only include the free preview.

Fetches go through a small proxy because Substack's API doesn't allow cross-origin browser requests.
